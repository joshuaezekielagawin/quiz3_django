# Quiz 3 - Django Student Records

A simple Django web application created for Quiz #3.

The application demonstrates the basic Django flow:

**Model → View → URL → Template**

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- Git
- GitHub
- PythonAnywhere

## Features

- Student records management
- Django Admin interface
- Student ID
- Full Name
- Course / Program
- Year Level
- Section
- Student records displayed on the homepage
